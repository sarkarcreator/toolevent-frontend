# Toolbox.Events Frontend

Next.js 15 frontend for [Toolbox.Events](https://toolbox.events), a free online event planning platform with practical calculators and AI-assisted planning tools.

The frontend contains only pages/components/client-side utilities. `/api/*` requests are proxied by Next.js to the separate backend using `BACKEND_API_URL`.

## Toolbox.Events

Visit the live platform: https://toolbox.events

Toolbox.Events provides event budget, profit, ticket pricing, break-even, ROI, wedding budget, catering, staffing, guest attendance and checklist tools, plus an AI event planner.

## Local development
1. Copy `.env.example` to `.env.local`.
2. `npm install`
3. `npm run dev`
